Three reasons to start here

HomeValue is built as a complete, inspectable machine-learning project: a documented dataset, a reproducible training pipeline, measured accuracy, and an interface that explains what it knows.

Data-driven estimation

Every estimate comes from a Random Forest regressor fitted on real recorded sales, never from a lookup table or a hand-written formula. Accuracy is measured on a held-out test set and published on the insights page.

Property insights

See which characteristics move the estimate, how the subject property compares with the training medians, and how price behaves against area, bedroom count and age across the whole dataset.

Easy comparison

Adjust one field at a time and resubmit to compare scenarios side by side. Each result page is shareable, so you can revisit or compare a specific set of property details later.

How the estimate is produced

The pipeline is the same one used during training, so what you enter is transformed exactly the way the model learned it.

  1. You describe the property

    Nine characteristics covering location, size, layout, age, parking and property type.

  2. Inputs are validated

    Range checks catch unrealistic entries, and unseen categories fall back gracefully.

  3. The saved pipeline transforms them

    Median imputation, scaling and one-hot encoding are applied from the fitted artifact.

  4. The model returns an estimate

    You receive a price, a price per square foot, and the factors that moved it most.
